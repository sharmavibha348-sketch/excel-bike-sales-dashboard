# Bike Sales Dashboard

## Overview
This project is an interactive Excel dashboard designed to analyze bike purchase behavior across different customer segments.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## KPIs
- Total Customers: 1000
- Bikes Purchased: 481
- Purchase Rate: 48.1%
- Average Income: $56.4K

## Key Insights
- Middle-aged customers purchase bikes most frequently.
- Customers with 0–1 mile commutes have the highest purchase rate.
- Customers who purchased bikes generally have higher average incomes.
